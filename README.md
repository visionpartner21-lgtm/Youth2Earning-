# Youth2Earning 🚀

Youth2Earning is a demo referral-based earning platform designed for learning and presentation purposes.

## 🔥 Features
- User Registration
- Referral System & Bonus
- Daily Login Bonus
- Wallet (Demo Coins)
- Withdraw Request (Demo Only)
- Admin Panel (Manual Approval)
- Telegram Bot Integration

## ⚠️ Disclaimer
This is a **demo / educational project only**.
No real money, crypto, or financial transactions involved.
